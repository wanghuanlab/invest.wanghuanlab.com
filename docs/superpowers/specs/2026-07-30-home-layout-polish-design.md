# Invest Lab 首页排版优化设计规格

**日期：** 2026-07-30  
**范围：** 仅首页（`HomeView` 及相关首页专用组件）  
**状态：** 已确认，待实现计划  
**参考：** 用户提供的 Invest Lab 研究台参考图

## 1. 目标

在现有实验室气质与内容模型上，把首页首屏排成更接近参考图的「左叙事 / 右摘要」编辑式布局，提升留白、层级与主题色标辨识度，不改全站壳层与其他页面。

## 2. 明确不做

- 不改主题页、文章页、About、Header/Footer/TopicRail 的整体结构（仅首页消费既有 API）
- 不新增「研究笔记｜方法框架｜数据索引｜阅读清单｜关于我」等无真实路由的底栏伪导航
- 不引入仪表盘卡片墙、厚阴影、圆角胶囊堆、紫渐变

## 3. 信息结构

### 3.1 首屏左栏

1. 小字标：`Invest Lab`（铜绿色）
2. 主标题：`个人投资思考笔记`
3. 副文案两行：`连接利率与资产，理解周期与结构，在不确定的世界里寻找可重复的思考。`
4. CTA：`浏览主题` → `#topics`
5. 说明：`静态 Markdown 研究库`（等宽小字，左侧铜绿竖线）
6. 主题色标行：六主题各一色块 + 中文名，链接到对应 `/topics/:slug`

### 3.2 首屏右栏（摘要卡）

容器：浅纸色底 + 墨蓝细描边，无大圆角无厚阴影。

**推荐阅读**

- 标题栏：左侧铜绿竖条 +「推荐阅读」；右侧「查看全部 →」锚到 `#latest`
- 正文：主题名 → 标题 → 日期 → 配图（约 3:2）→ 摘要
- 数据：`getFeaturedArticles()` 取第一篇；若无 featured，回退为最近一篇
- 配图：优先文章可选 `cover` frontmatter；缺省时若正文含首张 markdown 图则可用，否则不渲染空图框

**最近更新**

- 最多 3 条，排除当前推荐文
- 每行：主题色点 + 标题 + 日期
- 底：「查看全部更新 →」→ `#latest`

### 3.3 首屏以下

- `#topics`：现有 `TopicGrid`，与首屏间距收紧统一
- `#latest`：现有 `ArticleList`（`showTopic`），展示最近文章完整列表

## 4. 主题色标

固定映射（仅首页色点/色块使用，不改变全局 accent）：

| slug | 色值 |
|------|------|
| rates | `#1F6F5B` |
| bonds | `#8B6914` |
| stocks | `#0B3A5C` |
| gold | `#C4A035` |
| demographics | `#6B4C9A` |
| housing | `#2F6F8F` |

## 5. 布局与响应式

- 桌面：约 `7fr / 5fr` 或等价 grid（左叙事、右摘要），右栏 sticky 可选但不强制
- 移动：上左栏 → 下右栏 → 主题 → 列表
- 主内容区继续使用 `App.vue` 的 `max-w-6xl`

## 6. 技术边界

- 主要修改：`src/views/HomeView.vue`
- 可选抽取：`TopicSwatches.vue`（色标行）、`HomeReadingPanel.vue`（右栏）——仅当 HomeView 过长时抽取
- 可选扩展：`ArticleMeta.cover?: string` + frontmatter 解析；给当前 featured 文写上 `cover: /images/six-paths-for-ordinary-investors.png`
- 不动路由与内容加载主 API 契约（可向后兼容增加 `cover`）

## 7. 验收

1. 桌面首屏一眼可读：左品牌叙事、右推荐+最近更新
2. 六主题色标可点击并进入对应主题
3. featured 文标题/摘要/配图正确；无 featured 时不崩
4. CTA 与「查看全部」锚点滚动正常
5. 移动端无横向溢出；`prefers-reduced-motion` 下无强制动画
6. 现有测试仍通过；若新增 `cover`，补最小单测
